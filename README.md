# 空中之島 V1

第一人稱 3D 方塊小島，使用 HTML、CSS、JavaScript、three.js。所有遊戲資料在瀏覽器記憶體內，重新整理會重建小島與背包。

## 開啟遊戲

已安裝 Node.js 時，雙擊「啟動遊戲.cmd」；也可在本資料夾執行 `npm start`，然後開啟 http://127.0.0.1:4173 。請使用一般桌面瀏覽器並點擊「進入小島」。

這是靜態網站，Node.js 僅用來在本機提供檔案，沒有遊戲後端或帳號系統。亦可將檔案放到一般靜態網頁空間。直接雙擊 index.html 會受到瀏覽器模組載入限制。

## 操作

- WASD 移動，空白鍵跳躍，一格高低差會自動跨上；兩格高牆仍會阻擋。
- 按住左鍵挖掘，放開或換目標會重置進度。
- 靠近掉落物自動撿取，右鍵在瞄準表面旁放置。
- 1–8 或滾輪選擇方塊，F 全螢幕，Esc 暫停。
- 使用游標指向 6 格內的方塊挖掘，沒有中央十字；長按左鍵拖曳或方向鍵轉視角，右鍵點一下放置。
- 第一人稱右手會隨挖掘揮動。
- 初始背包為空。前方有泥土與石頭供測試，掉出世界回到出生點並保留背包。

## 驗證

`npm test` 執行世界邊界、挖掘進度與放置條件的邏輯測試。畫面和操作驗收見 VERIFY.md；學校舊電腦的 30 FPS 仍需指定電腦實測。
